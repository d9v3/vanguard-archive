Copies réduites de fichiers publics réels, lues seulement par les tests (include_bytes! sous cfg(test)) : rien n'entre
dans le programme. Chacune garde les champs du fichier d'origine pour quelques entrées ; seuls des champs trop gros
(artefacts, variations de langue) ont été retirés de cask-extrait.json. Copiées le 23 octobre 2026.

Les autres fichiers des tests de versions (Mozilla product-details, Chrome versionhistory, Edge, OfficeReleases, Adobe,
Brave, Microsoft AutoUpdate, avis de sécurité de Mozilla) n'ont pas de licence publiée, ou une licence qui demanderait
l'accord de l'auteur (MPL-2.0) : leurs fixtures sont inventées, écrites dans les tests.

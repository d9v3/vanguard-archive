GARDIEN pour macOS — comment le lancer
======================================
English: README.txt

Le programme : « gardien », dans ce dossier. macOS 12 Monterey et plus récents, Mac Apple Silicon (M1,
M2…) et Intel, rien à installer.


1. LE PLUS SIMPLE

   Double-cliquer « Lancer Gardien.command » à la racine de la clé : le Terminal s'ouvre avec le menu.


2. DANS LE TERMINAL

   Ouvrir le Terminal (Cmd+Espace, taper « Terminal », Entrée ; ou Applications > Utilitaires) et taper
   le chemin du programme, sans aller d'abord dans la clé avec « cd » : sur un autre Mac, Gardien remonte
   la clé en lecture seule pour la protéger, ce qui échoue si le Terminal y est ouvert.

     /Volumes/GARDIEN/macOS/gardien

   Astuces : taper « /Volumes/GA » puis la touche Tab pour compléter ; ou glisser le fichier « gardien »
   depuis le Finder dans la fenêtre du Terminal, puis Entrée.


3. COMMANDES UTILES

   Sans rien après « gardien » : le menu. Sinon (« gardien » = /Volumes/GARDIEN/macOS/gardien) :

     gardien complet              bilan complet : ce Mac, puis le réseau
     gardien complet --texte      même bilan, rapport en texte simple
     gardien corriger             bilan, puis chaque correction montrée et confirmée
     gardien machine              audit de ce Mac seulement
     gardien reseau               scan du réseau local
     gardien maj                  mises à jour : macOS, Homebrew, App Store…
     gardien reparer              réparations : Internet, DNS, disque plein…
     gardien nettoyer --liste     place à gagner, sans rien effacer
     gardien connexion            test de connexion : ping, débit, bufferbloat
     gardien antivirus <dossier>  analyser une clé, un disque ou un dossier (ClamAV)
     gardien --help               toutes les commandes (gardien <commande> --help : le détail)
     gardien --version            la version


4. BON À SAVOIR

   - Une correction demande ton mot de passe de session (sudo) au moment où tu l'acceptes, jamais avant.
   - Lancé depuis la clé, Gardien s'ouvre sans avertissement. Copié depuis Internet ou par AirDrop, macOS
     le bloque (« développeur non identifié ») : dans le Terminal, xattr -d com.apple.quarantine gardien,
     ou clic droit > Ouvrir dans le Finder.
   - Antivirus (ClamAV), logiciels et gaming passent par Homebrew, proposé s'il manque.
   - En anglais :  GARDIEN_LANG=en /Volumes/GARDIEN/macOS/gardien
   - Quitter : q dans le menu, ou Ctrl+C.
